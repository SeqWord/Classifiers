# Data

Reference genome used by the bundled example model.

| Path | Role |
|---|---|
| `reference/H37Rv.fasta` | H37Rv sequence for VCF/FASTA/FASTQ query |
| `reference/H37Rv.gbk` | GenBank annotation |
| `reference/reference_manifest.json` | File sizes and SHA-256 checksums |

AFRO example VCFs use contig name `M.tuberculosis_H37Rv`. Query samples should use the same coordinate system as this reference.
